# jemxiaolong.github.io

My portfolio — [jemxiaolong.github.io](https://jemxiaolong.github.io)

Next.js (static export) · TypeScript · Tailwind CSS. Bilingual (ES/EN) with a
light/dark theme, both persisted in `localStorage` and applied before first
paint so neither flashes on load.

```bash
npm install
npm run dev     # http://localhost:3000
npm run build   # static site in ./out
```

Deployed to GitHub Pages by `.github/workflows/deploy.yml` on every push to `main`.
